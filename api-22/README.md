# Provisional OpenCPN API 1.22 snapshot

This directory tracks the unstable API 1.22 header used by the coordinated
chart-safety development branches. It is intentionally not an API 1.21
extension: API 1.21 is released and locked.

The snapshot must be refreshed from the matching OpenCPN core branch while the
API 1.22 contract is under review. It should be replaced by the official
`OpenCPN/opencpn-libs` API 1.22 package once that API is published.
